接入方式　
请求体原样透传（messages / tools / stream 等全部字段不做任何改动），响应字节级回传。同一模型名可挂多个 Provider，按优先级自动故障转移。客户端带 X-Session-ID 头可开启会话粘性：同一会话固定走同一上游，仅在上游失败时才切换。
自动模型名 请求体 model 填这个名字（默认 auto）时，在所有可用模型里按优先级自动挑选，仅替换 model 字段、其余内容照旧透传
优先级数值越大越优先，用每行 ▲▼ 调整顺序
#模型Provider优先级今日用量 / 上限 (tokens)静音时段测试操作
Base URL 填到 /v1，例如 https://api.openai.com/v1
名称基址密钥上游余额操作
客户端携带 Authorization: Bearer sk-r-… 访问 /v1/*；一个 Key 都没有时代理入口不鉴权
