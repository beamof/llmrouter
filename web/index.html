管理令牌

服务端以 -admin-token 或环境变量 LLMROUTER_ADMIN_TOKEN 启动后，访问后台需要令牌。令牌仅保存在本机浏览器。

运行说明

  • 请求体原样透传（messages / tools / stream 等全部字段不做改动），响应字节级回传。
  • 客户端带 X-Session-ID 头可开启会话粘性：同一会话固定走同一上游，仅在上游失败时才切换；默认 1 小时无活动过期（可在上方调整），也可在活跃会话面板手动结束。
  • 每日上限与静音时段按服务器本地时间计算；静音时段支持跨零点，如 22:00~06:00。
  • 缓存命中优先读取 prompt_tokens_details.cached_tokens / input_tokens_details.cached_tokens，缺失时回落 DeepSeek 的 prompt_cache_hit_tokens 等字段（含在输入 token 内），首页单独展示。

添加 Provider

两种协议的基址可以不同（如智谱 Coding Plan 没有 /responses，可单独填 https://open.bigmodel.cn/api/v1）。余额查询地址可留空：智谱、DeepSeek 会自动使用官方余额接口。

复用 WorkBuddy / CodeBuddy 客户端登录态：扫描本机客户端目录（Windows: %LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth）或粘贴凭证 JSON 导入；导入后 llmrouter 用 refreshToken 自动续期，与客户端互不影响。上游仅支持 chat completions 协议。
