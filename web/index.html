管理令牌

服务端以 -admin-token 或环境变量 LLMROUTER_ADMIN_TOKEN 启动后，访问后台需要令牌。令牌仅保存在本机浏览器。

运行说明

  • 请求体原样透传（messages / tools / stream 等全部字段不做改动），响应字节级回传。
  • 客户端带 X-Session-ID 头可开启会话粘性：同一会话固定走同一上游，仅在上游失败时才切换，1 小时无活动过期。
  • 每日上限与静音时段按服务器本地时间计算；静音时段支持跨零点，如 22:00~06:00。
  • 缓存命中读取 prompt_tokens_details.cached_tokens，含在输入 token 内，首页单独展示。

添加 Provider

两种协议的基址可以不同（如智谱 Coding Plan 没有 /responses，可单独填 https://open.bigmodel.cn/api/v1）。余额查询地址可留空：智谱、DeepSeek 会自动使用官方余额接口。
